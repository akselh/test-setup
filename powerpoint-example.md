# Eksempelpresentasjon

Denne presentasjonen er en test. Claude gjør den om til en PowerPoint-fil.
Hvis PowerPoint-filen blir laget, kan maskinen din lage presentasjoner i workshopen.

## Hva testen viser

- Claude Code kjører på maskinen din
- Node.js er installert og virker
- `pptx`-skillen fra Anthropic får lov til å hente pakkene den trenger

## Slik bruker du dette i workshopen

Du skriver innholdet i en vanlig markdown-fil. Claude lager PowerPoint-filen.
Du slipper å flytte tekst inn i PowerPoint for hånd.

## Verktøy du trenger

| Verktøy | Hvorfor |
| --- | --- |
| Claude Code i Claude Desktop | Kjører hele workshopen |
| VS Code | Redigerer markdown-filene |
| Git | Henter og deler filer i teamet |
| Node.js | Word- og PowerPoint-eksporten bruker den |

## Oppsummering

Maskinen er klar når både Word-filen og PowerPoint-filen finnes.
